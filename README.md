# Travelplaner
A simple and interactive C-based terminal application that helps you choose a travel destination based on continent, country, and climate preference.

# About
This Travel Planner is built in C and allows users to explore the globe through a step-by-step terminal interface.

# Features

- Choose from all 7 continents.
- Explore 4 countries per continent.
- Get destination recommendations tailored by climate preference(Hot or Cold).
- Simple, user-friendly command line interface.
